# Elisabete Nogueira — PWA 1.1

Atualização visual e cadastro de perfil local.

## Novidades
- Primeiro acesso pergunta nome e permite foto opcional.
- Foto e nome personalizados ficam em `localStorage`, apenas no dispositivo (sem contas, sincronização ou coleta de idade).
- Cabeçalho com avatar, saudação e uma única engrenagem de configurações.
- Remoção de textos redundantes de marca e rodapé demonstrativo.
- Ícones vetoriais atualizados na navegação.
- Configurações permitem editar nome/foto, checar atualizações e acessar painel após 5 toques na versão.
- Nenhum login root foi adicionado. O painel **não é seguro** e não publica no GitHub.

## Publicação
Extraia este ZIP e envie **o conteúdo da pasta**, não a pasta em si, para a raiz do repositório GitHub Pages substituindo os arquivos existentes. Não delete os demais arquivos. Faça commit na branch publicada. Abra o PWA instalado para detectar a atualização 1.1.

## Avisos
A senha `CRYSTAL2026` ainda é demonstrativa, sem proteção de conteúdo real. O gesto de 5 toques não é autenticação. Dados locais podem ser apagados ao limpar dados do navegador. O cadastro aparece na primeira visita de cada dispositivo ou quando não houver nome salvo.
