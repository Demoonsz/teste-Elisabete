Autorizar administrador no GitHub

Antes de criar ou recuperar a senha root neste aparelho, comprove acesso ao repositório privado. Quem apenas encontrar esta página não conseguirá criar um administrador.

A senha root não fica no código público. Os dados de conexão só serão salvos após a verificação do token e da identidade root cadastrada no repositório privado.
