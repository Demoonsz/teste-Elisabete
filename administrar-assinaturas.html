Gerenciamento de assinaturas

Ferramenta administrativa. O arquivo com os nomes e códigos é criptografado no navegador e enviado ao repositório privado. A conexão pode ficar salva criptografada neste aparelho, protegida pela senha local do administrador.

Entrar como administrador

Usuário: root

Ao entrar, o painel recupera a conexão do GitHub e a frase de criptografia deste aparelho.

Primeira conexão ao GitHub

O repositório privado precisa ser criado manualmente no GitHub. Não coloque a frase secreta nem o token em arquivos do projeto. Se perder a frase secreta, não será possível recuperar os registros criptografados.

Conta do painel

Usuário: root. Escolha uma senha para desbloquear a conexão salva. Não precisa ser igual à frase secreta do banco.

A senha root não será escrita no código nem salva em texto aberto. Senhas curtas ou que já foram compartilhadas podem permitir a recuperação do token por quem obtiver os dados locais. Prefira uma senha forte e exclusiva.

Assinantes

Para cada novo assinante, gere um código aleatório e envie somente para a pessoa. O aplicativo consulta uma lista pública de hashes, sem nomes.
