Gerenciamento de assinaturas

Ferramenta administrativa. O arquivo com os nomes e códigos é criptografado no navegador e enviado ao repositório privado. Nenhum token ou senha é salvo no aplicativo.

Conectar ao seu GitHub

O repositório privado precisa ser criado manualmente no GitHub. Não coloque a frase secreta nem o token em arquivos do projeto. Se perder a frase secreta, não será possível recuperar os registros criptografados.

Assinantes

Para cada novo assinante, gere um código aleatório e envie somente para a pessoa. O aplicativo consulta uma lista pública de hashes, sem nomes.
